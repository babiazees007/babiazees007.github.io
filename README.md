## 🚀 Featured Projects

### 🤖 GenAI & Agentic AI

**[Hire Me Boss](https://github.com/babiazees007/hire-me-boss)**: Self-hosted, privacy-first ATS resume optimizer that runs entirely on local LLMs (Ollama) with a Flask backend. Analyzes resumes against job descriptions, rewrites bullet points, and identifies skill gaps with no data sent to cloud services. Includes ATS scoring, gap analysis, and PDF/DOCX export.

**[Stock Market Prediction using RAG + LLM + LangGraph](https://github.com/babiazees007/stock-market-prediction-using-rag-llm-langgraph)**: End-to-end prediction app combining XGBoost, technical indicators, RAG-based evidence retrieval, LLM-generated market interpretation, and LangGraph orchestration, served through FastAPI with an HTML/CSS/JavaScript frontend.

**[LlamaIndex Math Agent](https://github.com/babiazees007/lamaindex_Ai_chatbot_math_agent)**: Agentic chatbot built with LlamaIndex's ReAct framework, Ollama local LLMs, and a Gradio interface. Solves math queries step by step by choosing and running Python tools.

### 📊 Applied Machine Learning & Data Science

**[Customer Transaction Prediction & Intelligence Platform](https://github.com/babiazees007/Customer-Transaction-Prediction-Intelligence-Platform)**: Enterprise-style predictive modeling for retail banking (PRCP-1003), with LightGBM among the benchmarked models.

**[Portuguese Bank Telemarketing Intelligence](https://github.com/babiazees007/Bank_Marketing_Intelligence_)**: AI-powered lead propensity scoring and marketing analytics (PRCP-1000) using LightGBM, XGBoost, and Scikit-learn, with data-leakage handling around call duration.

**[FIFA 20 Player Skill Analysis](https://github.com/babiazees007/FIFA_20_Player_Skill_analysis)**: Unsupervised clustering and tactical analysis of 18,278 professional football players (PRCP-1004).

**[Retail Revenue Intelligence Dashboard](https://github.com/babiazees007/Retail-Revenue-Intelligence-Dashboard-Indian-E-Commerce-Sales-2018-2019)**: Sales performance dashboard for Indian e-commerce (2018-2019) with SQL schema design, data engineering pipelines, and live PostgreSQL queries.

**[Rising Water Flood Prediction](https://github.com/babiazees007/Rising_Water_Flood_Prediction)**: ML-powered web app that predicts flood risk from meteorological data, with early warnings, risk levels, and precautions.

### 👁️ Computer Vision & Medical AI

**[HematoVision](https://github.com/babiazees007/HematoVision-Advanced-Blood-Cell-Classification-Using-Transfer-Learning)**: Blood cell classification from microscopic images using transfer learning and CNNs, built to help automate haematology workflows.

**[Kidney Stone Detection using CNN](https://github.com/babiazees007/kidney_stone_detection_using_CNN)**: Web-based interface for a CNN model that analyzes uploaded CT scan images and returns AI-powered results.

**[Gesture Control System](https://github.com/babiazees007/Real_Time_Human_Computer_Interaction_Using_Computer_Vision)**: Real-time human-computer interaction app that controls system operations with hand gestures from a webcam, using MediaPipe, OpenCV, and Flask, with a web dashboard.
